# React API CRUD App

A simple React CRUD application using Axios, REST API, and JSON Server.

## Features

- Fetch employees using GET
- Add employee using POST
- Update employee using PUT
- Delete employee using DELETE
- Display employee data in a table

## Technologies Used

- React.js
- JavaScript
- Axios
- JSON Server
- REST API

## How to Run

### 1. Install dependencies

```bash
npm install
npm install axios
```

### 2. Start JSON Server

```bash
json-server --watch db.json
```

### 3. Start React App

```bash
npm run dev
```

## The application will run on:

http://localhost:5173

## API endpoint:

http://localhost:3000/employees
